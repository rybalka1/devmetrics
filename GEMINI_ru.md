# Обзор проекта

Это сервис для сбора метрик и оповещений, написанный на Go. Он состоит из двух основных компонентов: `agent`, который собирает метрики, и `server`, который их получает и сохраняет. Агент периодически собирает системные метрики и отправляет их на сервер. Сервер предоставляет HTTP API для получения и запроса метрик. Проект использует `chi` для маршрутизации, `zerolog` для логирования и хранилище в памяти (`MemStorage`) для метрик.

# Сборка и запуск

`Makefile` предоставляет необходимые команды для сборки и запуска проекта.

**Сборка проекта:**

*   `make all`: Собрать и агент, и сервер.
*   `make server`: Собрать сервер. Бинарный файл будет находиться в `cmd/server/server`.
*   `make agent`: Собрать агент. Бинарный файл будет находиться в `cmd/agent/agent`.

**Запуск проекта:**

1.  Запустите сервер:
    ```bash
    ./cmd/server/server
    ```
2.  Запустите агент:
    ```bash
    ./cmd/agent/agent
    ```

**Запуск тестов:**

*   `make tests`: Запустить интеграционные тесты, расположенные в директории `tests/`.

# Соглашения по разработке

*   **Структура проекта:** Проект следует стандартной структуре проектов на Go.
*   **Зависимости:** Проект использует `go mod` для управления зависимостями. Ключевые библиотеки включают:
    *   `github.com/go-chi/chi/v5` для HTTP-маршрутизации.
    *   `github.com/rs/zerolog` для структурированного логирования.
    *   `github.com/stretchr/testify` для утверждений в тестах.
*   **Тестирование:** В проекте есть набор интеграционных тестов в директории `tests/`, которые можно запустить с помощью команды `make tests`.
*   **Конфигурация:** Агент и сервер можно настроить с помощью флагов командной строки.
